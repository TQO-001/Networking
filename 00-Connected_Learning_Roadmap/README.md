## The core idea

There are no assigned weekdays and no overdue sessions. Work through numbered sessions in order. If you take a day or a week away, continue from the next unfinished session. The system measures what you can explain and do, not how many consecutive days you studied.

The files are plain Markdown. You can edit the checkboxes directly in VS Code or Obsidian. Keep a backup in Git if you already use Git for your study notes. Avoid building a separate app or database to manage this system.
