# Activate Windows XP by phone

↩ Back to the guide: [[07-legacy_industrial_pc_troubleshooting|Legacy industrial PC: dead machine, replacement and drivers]]

> **Use this when:** A fresh Windows XP install has no internet and needs activating.
> ◇ = **not from your notes** (general knowledge or the web). Double-check it on the device before relying on it.

## What you need
- [ ] A phone and the install ID shown on the activation screen

## Steps
- [ ] On the activation screen choose to activate **by phone**.
- [ ] Call the number from your notes: `080 143 4343`. ◇ Check this number is still correct before you rely on it.
- [ ] The automated voice sends you to the Microsoft **Product Activation Portal** (`https://aka.ms/WindowsActivate`). Follow the instructions on the blue screen. It took about 3 minutes.

## Check it worked
- [ ] The machine reports it is activated and the evaluation countdown is gone.

## Gotchas
- Your install showed an unexpectedly short grace period (about 3 days, not 30). Do not leave activation to the last minute.
