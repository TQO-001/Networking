# Boot and setup keys

↩ Back to the index: [[00-index|Jobbing index]]

> ◇ = **not from your notes**. Double-check on the device.

| Device | Key / action | What it does |
|---|---|---|
| HPE ProLiant DL360p Gen8 | **F8** during POST | iLO 4 setup (also "Set to defaults") |
| HPE ProLiant DL360p Gen8 | **F5** | HPE Smart Storage Administrator (per your notes; ◇ F8/F10 are the usual alternatives for the array and Intelligent Provisioning) |
| HPE ProLiant DL360p Gen8 | **F9** | ROM-Based Setup Utility (BIOS) |
| HPE ProLiant DL360p Gen8 | **F11** | One-time boot menu |
| HP Elite t655 thin client | **F9** | Boot menu (pick the USB) |
| HP thin client | ◇ **F10** | BIOS (Computer Setup), where "After Power Loss" lives if offered |
| HP ThinPro | Right-click desktop, or `Ctrl+Alt+Shift+S` | Switch to Administrator mode |
| Cisco fixed switch (2960 / IE-3000) | Hold the **Mode** button while powering on | Drops to the loader for password recovery |
| Console terminal | 9600 / 8 / N / 1 / no flow control | Cisco console settings |
