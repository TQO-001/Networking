## Moxa CLI Switch Commands
**Moxa switches utilize a Command Line Interface (CLI) heavily inspired by and structured similarly to Cisco iOS**. Moxa uses operating systems like MX-NOS or Next-Generation OS, grouping operations into identical hierarchy modes (User, Privileged, Global Config, and Interface Config).

- `enable`
- `configure terminal`
