# Checkpoint Firewall Configuration Task
Now that you've learnt how to configure switches, let's secure your network. The firewall, we'll be configuring is a NGFW specialized industrial firewall, it is a fairly new firewall and familiarizing yourself with the device and process of configuration will benefit you in the long term.

> [!NOTE] NOTE - It will be standardized in the Hulamin environment.

The **Check Point Quantum Spark 1570R** is an excellent and highly rated ruggedized next-generation firewall (NGFW) specifically built for harsh, industrial, and remote environments. To configure a **Check Point Quantum Spark 1570R** right out of the box, you do not need any special software. You just need a computer with an Ethernet port, a web browser, and an internet connection.
