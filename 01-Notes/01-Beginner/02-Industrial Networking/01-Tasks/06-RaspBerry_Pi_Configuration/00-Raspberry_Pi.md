A **Raspberry Pi** is a credit-card-sized single-board computer developed by the Raspberry Pi Foundation. Originally created to teach basic computer science in schools, it has become widely popular among developers, engineers, and hobbyists for tinkering, prototyping, and home automation.

### Core Hardware Features
- **Complete System on a Chip (SoC):** Integrates an ARM-based CPU, GPU, and RAM on a single circuit board.   
- **General-Purpose Input/Output (GPIO) Pins:** A 40-pin header that allows direct hardware interface with external electronics, sensors, relays, motors, and microcontrollers.   
- **Standard Connectivity:** Features USB ports, Ethernet, Wi-Fi, Bluetooth, HDMI output for displays, and a microSD card slot for operating system storage.   

### Common Use Cases
- **Home Automation & IoT:** Hosting lightweight servers, network-wide ad blockers (e.g., Pi-hole), or smart home controllers (e.g., Home Assistant).   
- **Embedded & Industrial Systems:** Edge computing, sensor data logging, and controlling industrial actuators via GPIO protocols like SPI, I2C, and UART.   
- **Software Prototyping:** Running Linux distributions (such as Raspberry Pi OS or Ubuntu) to test Python scripts, Docker containers, or web servers without dedicating desktop hardware.   
- **Media & Retro Gaming:** Serving as lightweight media centers or retro arcade emulators.
