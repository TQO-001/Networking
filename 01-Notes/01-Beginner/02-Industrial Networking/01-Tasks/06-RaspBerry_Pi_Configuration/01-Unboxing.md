## 1.1 Raspberry Pi 4 B 4GB Model B
The **Raspberry Pi 4 Model B (4GB)** is one of the most versatile single-board computers in the Pi lineup, striking a sweet spot between processing power, RAM capacity, and power efficiency for home servers, self-hosting, and hardware projects.

### Technical Specifications

| **Feature**        | **Specification**                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| **Processor**      | Broadcom BCM2711, Quad-core Cortex-A72 (ARM v8) 64-bit SoC @ 1.5GHz (rev 1.5+ boosts to 1.8GHz)                    |
| **Memory**         | 4GB LPDDR4-2400 SDRAM                                                                                              |
| **Networking**     | True Gigabit Ethernet (non-throttled), 2.4 GHz / 5.0 GHz 802.11ac Wi-Fi, Bluetooth 5.0 / BLE                       |
| **USB Ports**      | 2 × USB 3.0 ports, 2 × USB 2.0 ports                                                                               |
| **Video & Sound**  | 2 × micro-HDMI ports (supports up to 4K @ 60Hz single or dual 4K @ 30Hz), 4-pole stereo audio/composite video port |
| **Storage & Boot** | MicroSD card slot (high-speed SDR104), supports USB 3.0 SSD boot & Network/PXE boot                                |
| **Power Input**    | 5V DC via USB-C connector (requires minimum 3A / 15W supply)                                                       |
| **GPIO Header**    | Standard 40-pin GPIO header (fully backward compatible with earlier boards, supports SPI, I2C, UART, PWM)          |

### Ideal Applications for the 4GB Variant
- **Self-Hosting & Home Services:** Running Docker containers (Pi-hole, WireGuard/Tailscale VPN, Nextcloud, Nginx Proxy Manager, Portainer) without running into memory bottlenecks.   
- **Network & Edge Node:** Serving as a lightweight Linux jump box, local MQTT broker, or network monitoring probe.   
- **Light Desktop / Media Workstation:** Capable of running 64-bit Raspberry Pi OS or Ubuntu Server/Desktop for light web browsing, Python scripting, and terminal tasks.

## 1.4 Grove - Temperature&Humidity Sensor Pro(DHT22)
The **Grove - Temperature & Humidity Sensor Pro** is a high-accuracy digital sensor module based on the **DHT22** (also known as AM2302) module.

![[Pasted image 20260929121558.jpg]]

### Technical Specifications
* **Humidity Range:** 5% to 99% RH with an accuracy of ±2% RH.
* **Temperature Range:** -40°C to 80°C with an accuracy of ±0.5°C.
* **Operating Voltage:** 3.3V to 6V.
* **Low Power:** Uses 1–1.5mA during measurement and 40–50µA in standby mode.
* **Interface:** Digital output via a standard 4-pin Grove connector.

### Key Features
* **Built-in Microcontroller:** Uses an 8-bit chip to convert analog signals from the capacitive humidity sensor and NTC thermistor into digital outputs.
* **Pre-calibrated:** Factory-calibrated for reliable long-term stability.
* **Compatibility:** Works seamlessly with Arduino and Raspberry Pi (via Grove Base shields/hats) using standard libraries like the Seeed Grove DHT Library.
* **Industrial Upgrades:** Can connect to SenseCAP data loggers to function as a wireless LoRaWAN sensor.
